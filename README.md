# Prompt Engineering Platform

搭建属于自己的 Prompt 工程化平台。

## 项目简介

一个 Prompt 工程化平台，支持通过后台调试不同提示词模板、对比多模型生成效果，并对 Prompt 进行版本管理、评估和沉淀。

**技术栈**

| 层级 | 技术选型 |
|------|---------|
| 前端 | React 18 + TypeScript + Vite + Ant Design 5.x |
| 后端 | Python 3.12.13 + FastAPI + SQLAlchemy (async) + Alembic |
| 数据库 | MySQL (utf8mb4) |
| LLM 适配 | OpenAI / Claude / 通义千问 / 文心一言 / DeepSeek / Moonshot 等 |

## 项目目标

### Phase 1: Prompt 调试工作台（MVP）

从 0 到 1 跑通"写 Prompt -> 调用模型 -> 看结果"的核心链路。

- **Prompt 模板管理**：基于六大要素公式（RTF / CRAFT / C-C-A）和系统 Prompt 五大组件的结构化模板 CRUD
  - 变量插槽定义（`{{var}}` 占位符 + 类型/默认值/描述）
  - Few-shot 示例管理
  - 输出格式约束（JSON Schema / Markdown / 表格等）
  - 模型参数配置（temperature / top_p / max_tokens）
- **模型调用执行**：统一适配层调用 LLM，支持 SSE 流式输出
  - 执行记录存储（完整 Prompt、响应、token 用量、耗时、费用）
- **前端调试页**：变量输入 -> Prompt 预览 -> 模型选择 -> 流式输出展示

### Phase 2: 多模型对比与效果分析

同一个 Prompt 跑不同模型，并排对比，量化差异。

- **多模型适配层**：覆盖 OpenAI / Claude / 通义千问 / 文心一言等，统一接口与错误处理
- **对比实验**：同一输入并发调用多模型，并排卡片视图 + 差异高亮
- **五维度评估面板**：准确性 / 完整性 / 格式符合度 / 风格匹配度 / 稳定性
  - 自动评估引擎（标准答案对比 / 检查清单 / 程序化验证 / LLM-as-Judge / 多次一致性）
  - 1-5 分行为锚定评分卡
  - 评估权重配置（按任务类型调整客观/主观指标权重）
- **用量与成本统计**：按模型/模板/时间维度的 token 用量和费用看板

### Phase 3: 版本管理与测试体系

Prompt 迭代过程可追溯、可回滚、可回归测试。

- **版本管理**：每次修改自动快照，支持版本对比（diff）和回滚
- **调试向导**：四步引导式调试（问题识别 -> 问题分类 -> 针对性调整 -> 回归测试）
  - 偏差分类：理解偏差 / 格式偏差 / 质量偏差，自动推荐修复策略
- **渐进式优化追踪**：一次只改一个变量，记录改动前后评分，决策保留/回退
- **测试体系**：五类测试方法
  - 单次测试（冒烟）/ 多次测试（回归）/ 边界测试 / 压力测试 / A/B 测试
  - 测试数据集管理 + 测试报告（通过率 / 一致性率 / 失败分布）

### Phase 4: 高级能力与沉淀

多轮对话、链式 Prompt、团队协作、知识沉淀。

- **多轮对话管理**：上下文策略（全量历史 / 滑动窗口 / 自动摘要）
- **链式 Prompt**：拖拽式流程编排，多步骤串联执行
- **用户认证与团队协作**：JWT 认证、模板权限（private / team / public）、API Key 加密存储
- **知识沉淀**：模板归档、最佳实践库、优化案例库、导出功能

## 知识体系支撑

本项目基于系统化的 Prompt 工程知识体系构建，核心理论映射：

| 知识模块 | 在平台中的映射 |
|----------|--------------|
| Prompt 核心组成要素（指令/上下文/输入数据/输出格式） | 模板编辑器结构化字段 |
| 设计方法论（六大要素公式） | 模板创建流程的公式选择器 |
| 系统 Prompt 五大组件 | 系统 Prompt 编辑器分区块表单 |
| 评估维度与方法（五维度 + 五类测试） | 评估面板 + 测试中心 |
| 调试与优化方法论（四步调试 + 渐进式优化） | 调试向导 + 优化追踪器 |
| 评分体系设计（1-5 分行为锚定） | 评分卡配置 + 加权计算引擎 |
